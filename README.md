# Sibble

We are going to create a Scrabble web app using Lovable. My sister and I enjoy playing it online but we're annoyed by the ads. It should have following.

1. A simple Apple/Google authentication system
2. The traditional Scrabble board
3. A list of accepted English words
4. A way to connect two users to play a game online
5. A way for an admin (email with andrew.chepreghy@gmail.com) to play a game alone
6. A way to send a link to a user to open a game

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://letter-lane-lounge.lovable.app
